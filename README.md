# ArcAgent

A real time inbound voice agent that answers dental implant enquiry calls, qualifies the
caller, extracts an insurance signal, scores the lead deterministically, warm transfers hot
leads to a live coordinator, and books a callback with an SMS confirmation for everyone else.

Pipeline: Twilio Media Streams (mulaw 8 kHz) to Deepgram streaming STT to a LangGraph agent
to Cartesia streaming TTS and back to Twilio.

> Status: in development. Result tables in this README are generated from the database by
> `scripts/render_eval_results.py`. Sections marked TODO_OWNER are filled in from measured
> runs, not estimates.

## Why this exists

Paid search leads for high ticket dental work decay in minutes. Practices lose a large share
of inbound calls to voicemail, hold time, or an untrained front desk. ArcAgent answers every
call immediately, qualifies to the same standard every time, and gets a hot lead onto the
phone with a coordinator while the caller is still on the line.

## What is in scope

- Inbound PSTN handling over Twilio bidirectional Media Streams
- Streaming STT with endpointing and interim results
- LangGraph qualification conversation with per node structured outputs
- Streaming TTS with barge in
- Deterministic lead scoring from extracted fields, never an LLM judgement
- Warm transfer for hot leads, callback booking plus SMS for the rest
- Full persistence of calls, turns, leads, scores, and per stage latency
- A fixed 30 persona evaluation harness with run over run comparison

## What is out of scope

- Outbound dialling
- Practice management or EHR integration
- Real insurance eligibility verification. The agent extracts the signal, it does not verify coverage
- A full Spanish conversation. Spanish is detected and routed to a callback
- Payment collection and financing applications
- Multi tenant configuration
- A HIPAA compliant production deployment. The design and the gaps are documented in
  [docs/compliance_design.md](docs/compliance_design.md)

## Running locally

```bash
cp .env.example .env          # fill in your own credentials
docker compose up -d          # postgres 16
uv venv && uv pip install -e ".[dev,agent]"
alembic upgrade head
uvicorn arcagent.app:app --reload
ngrok http 8000               # point the Twilio voice webhook at $PUBLIC_URL/voice/inbound
```

Tests: `pytest -q`. Lint: `ruff check . && ruff format --check .`
Evaluation: `python -m evals.run_text --run-name <name> --repeats 3`
